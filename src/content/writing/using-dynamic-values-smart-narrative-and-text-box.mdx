When you want to summarise key metrics in your report, the go-to visual you will probably use is the ubiquitous card visual. However, if you knew how to use dynamic values in the Smart Narrative Visual or Text box, there is an alternative approach from sticking a plethora of cards on the canvas. The problem with using cards is that you need a separate card for every metric you want to use in your summary. Take the example below, for example. Here, we are summarising sales for salesperson "Abel" for the region "Germany" in 6 separate cards at the bottom left of the canvas:

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/01-six-cards.jpg" alt="A wine sales report filtered to salesperson Abel and the region Germany, with six cards at the bottom left: Total Sales, Avg Sales, Max Sales, Total Qty, Avg Qty and Max Qty." />

Whereas we could simply replace all 6 cards with one visual, as shown below. Welcome to the Smart Narrative visual a.k.a. the Text Box!

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/02-text-box-summary.jpg" alt="The same report with the six cards replaced by one text box headed In Germany for salesperson Abel, listing the six figures with each region, name and figure underlined as a dynamic value." />

Although the Text Box and the Smart Narrative visuals are essentially the same thing, there is a difference. If you select the Smart Narrative visual from the Visualizations gallery,…

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/03-smart-narrative-icon.jpg" alt="The Visualizations gallery with the Smart Narrative icon outlined in red." />

…Power BI will automatically summarise the data comprising the visuals on the page, whereas if you select a Text Box, you will need to generate the summary values yourself.

For example, if I insert a Smart Narrative visual onto my page, these are the summaries that the Smart Visual will generate: -

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/04-smart-narrative-summary.jpg" alt="A Smart Narrative visual beside the report, with generated sentences such as which wine had the highest and lowest Total Sales, Merlot's share of Total Qty and when Total Sales for each type started trending up, each figure underlined." />

All the values with a blue underline (the underline doesn't show when you publish) are dynamic values, generated by the visual. You can click on any of these values to see a description of them and format them if required.

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/05-auto-value-pane.jpg" alt="A red arrow from the first value in the narrative to its pane, which says the value was automatically generated while summarizing the report, as Max Total Sales by WINE, with currency formatting and the name V1." />

You can add your own dynamic values into the Smart Narrative. To do this, type the text you want and then to insert a value click on "Value" at the top of the visual:-

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/06-value-button.jpg" alt="The narrative's toolbar with the Value button outlined in red, above the typed text You are looking at data for." />

In "How would you calculate this value" type the value you want to insert. You can use natural language here, just as you would in Q&A.

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/07-value-dialog.jpg" alt="The Value pane, Create a dynamic value that updates, with Name of salesperson typed under How would you calculate this value and suggestions below it." />

The blue line under any text you have typed indicates that the Smart Narrative has recognised the natural language you have used:-

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/08-salesperson-value.jpg" alt="The narrative now reads You are looking at data for Abel, with Abel outlined in red." />

Click Save to insert the value into the Smart Narrative.

Now you know how to add your own values to the Smart Narrative, you could instead just use a Text Box and build your own smart summaries.

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/09-text-box-icon.jpg" alt="The Text box button." />

If you don't have existing measures that you want to use, you can ask the Smart Narrative to do the calculation for you. This is one of the great benefits of using these dynamic values, that you don't always need to know how to do the DAX calculation!

To edit a value, click on it and then use the "Review" button. Then click on the pen button.

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/13-review-pane.jpg" alt="The Review pane, Review and edit the values in your narrative, listing #Value, #Value 2 and #Value 3, with the Review button and the first value's pen button outlined in red." />

The Smart Narrative and Text Box can make great alternatives to using multiple cards. However, we can take this one stage further because sometimes the Text Box is not an alternative to multiple card visuals but supplies a necessary narrative in its own right.

Take this example where we have filtered "Bordeaux" wine and a start and end range of transaction dates. We want to generate a narrative to explain whether the quantity has increased or decreased. We can do this using a Text Box with the dynamic values being supplied by either measures or by natural language.

<Screenshot src="using-dynamic-values-smart-narrative-and-text-box/14-bordeaux-narrative.jpg" alt="Slicers selecting Bordeaux and the dates 19 and 27 January 2017, beside a text box reading On 27 January 2017 the Qty for Bordeaux was reduced from 176 to 127, a difference of -49 from 19 January 2017, and a table of Total Qty by sale date with those two dates outlined in red." />

These are the measures I inserted into each "Value" of the Text Box, but I could also use natural language:-

- **On** End Date = `LASTDATE(SALES[SALEDATE])` or just type "last saledate"
- **the Qty for** Wine Name = `SELECTEDVALUE(WINESTABLE[WINE])` or just type "wine name"
- **was** Up or Down = `IF([Start Value] > [End Value],"reduced","increased")`
- **from** Start Value = `CALCULATE(SUM(SALES[QUANTITY]), SALES[SALEDATE]=MIN((SALES[SALEDATE])))` or just type "first total qty"
- **to** End Value = `CALCULATE(SUM(SALES[QUANTITY]), SALES[SALEDATE]=MAX((SALES[SALEDATE])))` or just type "last total qty"
- **a difference of** Difference = `[End Value] - [Start Value]`
- **from** Start Date = `FIRSTDATE(SALES[SALEDATE])` or just type "first saledate"

So next time you feel the urge to dump lots of cards on your report page, consider using a Text Box instead. But better still, why not generate your own smart narratives that can tell the story of your data that truly inform.
